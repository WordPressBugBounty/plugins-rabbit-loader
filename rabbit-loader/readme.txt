RabbitLoader WordPress connection and performance dashboard.

== Description ==

The v6 rebuild keeps the proven v5 connection flow and introduces the redesigned RabbitLoader WordPress admin UI.

Connected navigation:
* Dashboard
* Optimization
* Usage
* Settings
* Help

The dashboard continues to read the existing RabbitLoader report/overview data.
